# Secure Network Configuration & Hardening Lab

## Overview
This project demonstrates the configuration and hardening of a small enterprise network, including router setup, endpoint validation, and system security policies.

## Key Components
- Router configuration using CLI
- IP address segmentation across multiple subnets
- Endpoint connectivity validation
- Windows Group Policy security hardening
- Firewall configuration
- Virtualization and sandboxing analysis

## Technologies Used
- Cisco IOS CLI
- Windows Group Policy Editor
- Networking (TCP/IP, Subnetting)
- Cybersecurity Hardening Techniques

## Project Highlights
- Configured multiple network interfaces with proper IP addressing
- Verified connectivity using `ipconfig` and interface commands
- Implemented security policies to reduce attack surface
- Applied firewall configurations to control traffic
- Analyzed virtualization for secure sandboxing
